Diseño UX/UI para zembra

Aplicación móvil AgroTech orientada a agricultores: diagnóstico visual de cultivos, registro de tareas, asesoría técnica y una experiencia clara para usuarios con baja familiaridad digital.

Resumen

Zembra propone una experiencia móvil para acompañar al agricultor desde el registro inicial hasta el diagnóstico del cultivo, el control de tareas y la conexión con servicios de apoyo agro.

Problema

Los agricultores suelen registrar actividades de forma manual, tienen dificultad para acceder a información confiable y necesitan orientación práctica cuando aparecen síntomas o manchas en los cultivos.

Objetivo

Diseñar una app sencilla, visual y guiada que permita registrar información, identificar problemas del cultivo y activar acompañamiento técnico sin aumentar la carga cognitiva.

Sitemap & flujos principales

Arquitectura de información

Tres rutas críticas para el MVP

La arquitectura prioriza las acciones que más valor generan desde el primer uso: crear cuenta, registrar actividades y diagnosticar un problema del cultivo a partir de una imagen.

1. Registro del agricultor

Ingreso por número, datos personales, tipo de usuario y registro de finca o cultivo.

2. Registro de tareas

Creación, guardado y confirmación de actividades del cultivo.

3. Diagnóstico

Carga de imagen clara, validación y resultado del diagnóstico.

Sistema de diseño

Atomic design

Componentes simples, estados claros y lenguaje visual agro

El sistema visual parte de átomos y moléculas reutilizables: botones, inputs, estados de error, tarjetas, buscadores, calendarios, formularios y componentes de comunicación.

Color

Verde para crecimiento y acción; naranja para énfasis, alertas y acciones principales.

Accesibilidad

Jerarquías grandes, botones amplios y estados visibles para usuarios no expertos.

Prototipo de alta fidelidad

Mobile prototype

Primer contacto claro y enfocado en confianza

La pantalla inicial usa una narrativa cercana al campo, CTA grandes y opciones de registro comprensibles. La prioridad es que el agricultor entienda qué debe hacer y por qué la app le sirve para cuidar sus cultivos.

Resultado UX

La propuesta convierte necesidades agrícolas complejas en una experiencia móvil progresiva: primero confianza y registro; luego seguimiento, diagnóstico y acompañamiento.

3Flujos críticos priorizados para el MVP: registro, tareas y diagnóstico.
4Capas de valor: información, control, diagnóstico y conexión con expertos.

Cambios clave propuestos

  • check_circleSeparar los flujos por intención: entrar, registrar cultivo, guardar tareas y diagnosticar.
  • check_circleUsar microcopy claro para usuarios que no dominan herramientas digitales.
  • check_circleDiseñar estados de validación para calidad de foto, guardado de tareas y confirmación.
  • check_circleConstruir una base visual escalable para mercado, asesorías, clima e indicadores agrícolas.

lightbulbAprendizajes

  • •En productos agro, la claridad visual es tan importante como la precisión técnica.
  • •La confianza se construye mostrando qué dato se guarda, por qué se solicita y qué acción sigue.
  • •El diagnóstico debe acompañarse de orientación accionable, no solo de un resultado.

Conclusión UX senior

Zembra debe sentirse como una herramienta de campo: simple, confiable y útil en el momento exacto en que el agricultor necesita tomar decisiones sobre su cultivo.
